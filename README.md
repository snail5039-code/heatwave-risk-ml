# 머신러닝 기반 고령자 폭염 외출 위험도 예측

## 프로젝트 주제

기상 데이터와 온열질환 발생 데이터를 활용해 폭염 시 고령자의 외출 위험도를 예측하는 프로젝트입니다.

핵심 질문은 다음과 같습니다.

> 오늘의 기온, 습도, 풍속, 일조량 같은 기상 조건에서 고령자가 외출하면 얼마나 위험할까?

## 목표

- 2025년 온열질환 발생 현황과 기상 데이터를 결합한다.
- 날짜와 지역 기준으로 폭염 위험 요인을 분석한다.
- 머신러닝 모델로 온열질환 발생 위험도를 예측한다.
- 최종적으로 고령자 외출 위험도를 `낮음 / 보통 / 높음 / 매우 높음`처럼 단계화한다.

## 사용할 데이터

| 파일 | 내용 | 용도 |
| --- | --- | --- |
| `heat_illness_2025_unified.csv` | 2025년 온열질환 신고현황 통합 데이터 | 정답 데이터, 발생자 수 분석 |
| `OBS_ASOS_DD_20260830192528.csv` | 2025년 ASOS 일별 기상 데이터 | 기온, 습도, 풍속, 강수량, 일조시간 등 feature |

## 온열질환 데이터 구성

`heat_illness_2025_unified.csv`에는 다음 정보가 포함되어 있습니다.

- 날짜별 전국 온열질환자 수
- 날짜별 시도/시군구 온열질환자 수
- 시도/시군구별 전체 합계
- 연령별 온열질환자 수
- 발생시간별 온열질환자 수

검증된 총 환자 수는 `4,460명`입니다.

## 기상 데이터 구성

`OBS_ASOS_DD_20260830192528.csv`에는 다음 기상 정보가 포함되어 있습니다.

- 평균기온
- 최저기온
- 최고기온
- 일강수량
- 평균 풍속
- 평균 상대습도
- 합계 일조시간
- 합계 일사량

기간은 `2025-05-15 ~ 2025-09-30`입니다.

## 분석 기준

온열질환 데이터는 `2025-05-15 ~ 2025-09-25`까지 있으므로, 기상 데이터도 같은 기간까지만 사용합니다.

기본 병합 기준은 다음과 같습니다.

```text
온열질환 데이터: date, region
기상 데이터: 일시, 지점명
```

## 머신러닝 방향

예측 대상은 다음 중 하나로 설정할 수 있습니다.

- 날짜별 온열질환자 수 예측
- 온열질환 발생 위험 등급 분류
- 고령자 기준 외출 위험도 분류

사용 후보 모델:

- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost 또는 LightGBM
